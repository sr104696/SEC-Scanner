6) SERVER EXTRACTION ENGINE (REQUIRED LOGIC)
In `src/server-lib/sec/sec-financials.ts`, implement deterministic functions:
1. `resolveCik(ticker)`:
   - Fetch `https://www.sec.gov/files/company_tickers.json`.
   - Match uppercase ticker.
   - Return zero-padded 10-digit CIK and entity name.
2. `secFetch(url)`:
   - Send `User-Agent` with contact email.
   - Default fallback user-agent string if env var missing/invalid.
3. `pickUnits(facts, conceptCandidates, preferredUnits)`:
   - Merge concept synonyms from `us-gaap` and `dei`.
   - Dedupe by `(start|end)` using latest `filed` date.
4. `classify(unit)`:
   - Quarterly if duration 80–100 days.
   - Annual if duration 350–380 days.
   - Instant when no `start`.
   - Treat other durations as annual/YTD bucket candidates.
5. `bucketFlow(units, isPerShare=false)`:
   - Build quarterly and annual maps.
   - Derive Q4 as `Annual - (Q1+Q2+Q3)` only for non-per-share metrics.
   - Skip Q4 derivation for per-share series (EPS, dividends/share).
6. Sorting rule:
   - If FY and Q4 share end date, FY row must sort before Q4.
7. Dividend logic:
   - `forwardAnnualDividendRate = 4 * latest quarterly DPS`.
   - Keep trailing annual dividend rate separately.
8. Content-type guard:
   - Reject SEC responses that are not JSON (throttling HTML pages).
9. Return assembled `SecResponse` with snapshot + periods + filings.
